## 这是什么

**NailMirror** 是一款面向 C 端用户与 B 端美甲商家的微信小程序：把手部照片与款式参考图融合，生成逼真的试戴效果；同时提供款式库、热度榜单、商家运营等完整链路。

| 面向 | 能力 |
|------|------|
| **消费者** | AI 云试戴 · 50+ 真实款式（每日更新）· 小红书全网热款 · 筛选排序 · 收藏与高清出片 |
| **商家** | 身份认证 · 款式库管理（查看 / 上传 / 下架）· 店铺信息配置 · 日更数据看板 · 运营策略 |
